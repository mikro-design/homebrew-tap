## Updating a formula

Formulae here are generated, never hand-edited: each one names the exact
archives a release published and their checksums, and a hand-edited copy drifts
silently. After tagging a release upstream, download `super-herdr.rb` from that
release and commit it here unchanged. Upstream renders it with
`scripts/render-packaging.sh` from the release's own signed `SHA256SUMS`.
